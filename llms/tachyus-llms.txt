# Tachyus — Tachapps API

> Tachyus provides AI-powered operational optimization and GHG emissions
> management software for the energy sector (Strateon, Aqueon, Aurion). The
> Tachapps REST API is organized around Projects, Wells, and Production Data,
> uses Bearer API-token auth, JSON over HTTPS, cursor pagination, and per-plan
> rate limits. Generated by API Evangelist from the published documentation
> (no provider-published llms.txt was found).
